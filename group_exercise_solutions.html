1. A radio link at 40 KHz can transmit a signal at 100 mW and the channel has 10 mW of noise. What is the capacity of the channel?
S/N = 100 mW / 10 mW = 10  (= 10·log1010 = 10 dB)
C = B · log2(1 + S/N) = 40,000 · log2(11)
log2(11) = log10(11) / log10(2) = 1.0414 / 0.3010 ≈ 3.46
C ≈ 40,000 × 3.46 ≈ 138.4 kbps

5. If we use parity check for a 5-bit word, how many 2-bit errors may be undetectable?
A single parity bit misses every even number of bit errors → all 2-bit errors are undetectable. Count = number of ways to pick 2 bits:
• 5-bit word including the parity bit (like 1001P): C(5,2) = 5·4/2 = 10
• 5 data bits + 1 parity bit (6 bits): C(6,2) = 6·5/2 = 15  (state your assumption)
6. If we use 1 bit for error detection of 5-bit words, which of 1-bit parity (assuming up to 2-bit errors) or CRC would have fewer non-detectable errors?
Step 1 – Which CRC? 1 check bit → C(x) has degree 1 → 2-bit generator: 10 (x) or 11 (x + 1). 10 always leaves remainder 0 (useless), so the 1-bit CRC must use C(x) = 11.

Step 2 – Compute both check bits for data 10110. 
Parity (even): 1 0 1 1 0 → three 1s (odd) → parity bit = 1

CRC with 11:  append 1 zero → 101100
  101100
  11          XOR → 011100
   11         XOR → 000100
      11      XOR → 000010
       remainder = 1        → CRC bit = 1   (same as parity!)

Sent frame (both schemes): 10110 1
Step 3 – Receiver side, same frame 101101.
CaseReceivedParity check (# of 1s)CRC check (÷ 11 remainder)Result
No error1011014 → even ✓0 ✓OK
1-bit error (bit 1)0011013 → odd ✗1 ✗both detect

Why always the same: each XOR with 11 flips two neighbouring bits → the number of 1s changes by 0 or 2 → odd stays odd, even stays even. The final 1-bit remainder is therefore 1 exactly when the number of 1s is odd = the even-parity bit.

Step 4 – Count (6 bits = 5 data + 1 check).

Answer: neither — both have 15 non-detectable errors. With only 1 bit, CRC becomes parity; CRC is stronger only with more check bits.
7. How many 2-bit errors can be undetected by checksum in 5-bit words?
Assumption: one 5-bit data word + its 5-bit checksum are sent (10 bits).

Step 1 – Example. 
data      D = 10110
checksum  C = 01001   (complement of D)
D + C       = 11111   → complement = 00000 → no error
Step 2 – Why some errors are missed. C is the complement of D, so in each bit position one of them is 0 and the other is 1. If the same position is flipped in both, the 0 becomes 1 and the 1 becomes 0 → D + C is still 11111 → the receiver sees no error.

Step 3 – All undetected 2-bit errors.

Answer: 5 undetectable 2-bit errors (one per bit position) out of C(10,2) = 45 possible 2-bit errors.

9. (Optional) Design a coding scheme to transmit 4-bit words (16 combinations) where a string of words cannot contain more than 4 consecutive 1s or 0s.
Idea (like 4B/5B): map each 4-bit word to a 5-bit code that does not start and does not end with three equal bits.
Then at the boundary between two codes at most 2 + 2 = 4 equal bits can line up, and inside a code the longest run is 3.
18 of the 32 five-bit codes satisfy the rule (32 − 8 − 8 + 2); choose 16:

Key rules: dB → S/N: divide by 10, take 10 to that power · checksum: add, wrap carry, complement · CRC: append r zeros (r = degree = bits of C(x) − 1), XOR-divide, remainder = CRC · parity misses all even-bit errors, count with C(n,k).
