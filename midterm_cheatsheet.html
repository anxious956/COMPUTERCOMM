Encoding

  • NRZ 1 = high, 0 = low. Problems: baseline wander, clock recovery.
  • NRZI 1 = transition, 0 = stay (fixes 1s, not 0s). Start level only matters for NRZI.
  • Manchester mid-bit transition, bit rate = ½ baud rate (10 Mb/s → 20 Mbaud, 50%). Used by Ethernet.
  • 4B/5B ≤ 1 leading 0, ≤ 2 trailing 0 → ≤ 3 zeros in a row, 80%, sent with NRZI. 0000→11110, 0001→01001, 0010→10100, 1111→11101; 11111 idle, 00000 dead, 00100 halt.
  • 2B/3B (EX3): no > 2 zeros → drop codes starting or ending with 00 → 010, 011, 101, 110, 111.
  • FSK: same amplitude, one frequency for 1, another for 0.

Parity

  • Even: total 1s even; odd: total 1s odd. Detects odd # of errors, misses every even # (each flip ±1).
  • 1001P odd → P=1 → 10011; all C(5,2)=10 2-bit errors missed: 01011 00111 00001 00010 11111 11001 11010 10101 10110 10000.
  • 2-D: row P + column P byte; catches all 1/2/3-bit, most 4-bit (misses rectangle); corrects 1 bit (bad row × bad col). Used in BISYNC.
  • 1-bit CRC must use C(x)=x+1=11 → same as even parity (XOR 11 changes # of 1s by 0 or 2).

Checksum (1's complement)

  00010101 + 10110011 = 11001000 (Sum1)
+ 01000001          = 1 00001001 (Sum2)
plus carry          = 00001010
complement          = 11110101  ← transmitted
Receiver: sum all + checksum = 11111111 → complement 0 = OK
  • Carry can be "10" (3 words) — add it back as is. Internet checksum = 16-bit words, IP (not link level).
  • Misses reordered fields and errors that cancel (same bit position flips 0→1 in one word, 1→0 in another).
  • Hex fields: a2:06:23 → sum cb → checksum 34.

CRC

  • Bits ↔ polynomial: 110001 = x5+x4+1. C(x) degree r → append r zeros, XOR-divide, remainder (r bits) replaces the zeros. Receiver remainder 0 = OK. Only C(x) must be known.
  • Window: if it starts with 1 → XOR C(x); drop first bit; bring down next bit.
  • Detects: all 1-bit (xk and x0 terms ≠ 0); all 2-bit (factor with ≥ 3 terms); any odd # (factor x+1); bursts < k bits. Used in HDLC, DDCMP, CSMA/CD, Token Ring. CRC-32 for Ethernet.
  • C(x) = xm (e.g. 100) → R=0 iff last m bits are 0 → 6-bit M: 24−1 = 15 values (4, 8, …, 60).
M=1101, C=1011: 1101000 → 1101⊕1011=0110 → 1100⊕1011=0111
→ 1110⊕1011=0101 → 1010⊕1011=0001 → R=001 → send 1101001

Ethernet 802.3

  • Xerox PARC mid-70s; root = ALOHA (Hawaii); DEC+Intel+Xerox 10 Mb/s 1978; Fast 100, Gigabit 1000.
  • CSMA/CD, Manchester, 1-persistent. Segment 500 m coax (50 Ω), ≤ 4 repeaters, reach 2500 m. 10Base2 = 10 Mb/s baseband 200 m; 10BaseT = twisted pair 100 m, hub.
  • Frame: preamble 64 · dst 48 · src 48 · type 16 · data 46–1500 B · CRC 32. Min 64 B = 14 hdr + 46 data + 4 CRC.
  • Collision → 32-bit jam; runt = 96 bits (64+32). Worst case detect at t + 2d.
  • Address 48 bits, in adaptor ROM, 24-bit maker prefix (AMD 8:0:20). All 1s = broadcast; first bit 1 = multicast. Accepts own, broadcast, chosen multicast. < 200 hosts typical (max 1024).

Wireless / 802.11

  • FCC allocates; license-exempt → power limit + spread spectrum (frequency hopping / direct sequence, n-bit chipping → n× wider).
  • 802.11: FH 79×1 MHz or DS 11-bit chip, 2.4 GHz 2 Mb/s · b 11 Mb/s 2.4 GHz · a 54 Mb/s OFDM 5 GHz · g 54 Mb/s OFDM 2.4 GHz.
  • Hidden: A, C reach B not each other → collide at B. Exposed: C hears B→A, wrongly won't send to D.
  • MACA: RTS → CTS (length). Hear CTS → quiet; hear only RTS → may send. MACAW adds ACK. No CD: no CTS → backoff.
  • APs + distribution system (layer 2). Active scan: Probe → Probe Resp → Assoc Req → Assoc Resp. Passive: Beacon.
  • Frame: 4 addr, data ≤ 2312 B, CRC 32. ToDS=FromDS=1: Addr1 final dst, Addr2 last AP, Addr3 first AP, Addr4 source (E, AP-3, AP-1, A).
  • Bluetooth 2.45 GHz, 10 m, PAN, 2.1 Mb/s, piconet 1 master + 7 slaves (parked). ZigBee 802.15.4 low power.

Layers, Internet, History

  • TCP/IP 4 layers: App, Transport, Network, Link; routers = bottom 2. OSI 7 (adds Phy, Session, Presentation).
  • DL: frames over a link (sync, error, flow) · Net: routing, addressing · Transport: reliable delivery, flow, error recovery.
  • HW (MAC) @ only to the next hop / closest router; same LAN = same network ID.
  • Protocol = syntax, semantics, timing. Standard = agreed rules. Internet Draft (6 months) → RFC. IETF, IAB, ISOC, IRTF, IANA, ICANN.
  • 1957 Sputnik → ARPA · 1962–68 packet switching · 1969 ARPANET (UCLA, SRI, UCSB, Utah) · 1971 e-mail · 1973 TCP/IP · 1982 TCP/IP for ARPANET · 1984 DNS · 1991 WWW (CERN) · 1993 Mosaic.
