Conventions used by the professor (from his HW2 solution and slides):
  • Manchester: 0 = low→high, 1 = high→low (= NRZ XOR clock). He draws a CLK line above NRZ and Manchester.
  • 2-D parity corner bit: parity of the P column (the row-parity bits). HW2: P column 0,0,1 → odd parity → corner 0.
  • Checksum: add two words → add the third → add the carry back ("plus carry") → complement.
  • Counting errors: written as n!/(k!(n−k)!) — e.g. 5!/(3!2!) = 10.
  • CRC answers may be written with a leading 0 (EX3: "R = 0111" for a 3-bit remainder 111).

Ethernet (802.3)

  • Xerox PARC, mid-1970s; root protocol ALOHA (U. of Hawaii, medium = air). DEC + Intel + Xerox 10 Mbps standard 1978 → IEEE 802.3; Fast Ethernet 100 Mbps, Gigabit 1000 Mbps.
  • CSMA/CD: carrier sense (tell idle from busy) + collision detection (listen while transmitting). Uses Manchester encoding.
  • Coax segment ≤ 500 m (50 Ω), ≤ 4 repeaters between hosts, total reach 2500 m. 10Base5 (original), 10Base2 = 10 Mbps, baseband, 200 m; 10BaseT = twisted pair, 100 m, hub.
  • Frame: preamble 64 bits · dst 48 · src 48 · type 16 (demux key) · data 46–1500 bytes · CRC 32.
  • Address: 48 bits, belongs to the adaptor (ROM), written as 6 hex bytes, leading 0s dropped (8:0:2b:e4:b1:2). Manufacturer prefix 24 bits (AMD = 8:0:20). All 1s = broadcast; first bit 1 but not all 1s = multicast. Adaptor accepts: own address, broadcast, multicast it was told to accept.
  • Transmitter: idle → send now; busy → wait until idle then send at once = 1-persistent. Collision → send 32-bit jam then stop. Runt frame = 64 preamble + 32 jam = 96 bits. Retry with exponential backoff.
  • Works best lightly loaded; typically < 200 hosts (max 1024); easy, cheap, no routing tables.

Random access (CSMA notes)

ProtocolChannel idleChannel busy
Pure ALOHATransmit at arbitrary times — no carrier sense. Vulnerable period = 2 frame times.
1-persistent CSMAtransmit (probability 1)keep listening, transmit as soon as idle
Non-persistent CSMAtransmitwait a random time, start again
p-persistent CSMA (slotted)transmit with prob. p, defer to next slot with q = 1−pwait a random time, start again
All: collision → wait a random time and start over. Data link layer = LLC + MAC sublayers.

Wireless / 802.11 / Bluetooth / ZigBee

  • FCC allocates bands. License-exempt bands: limited power + must use spread spectrum: frequency hopping (pseudorandom sequence of frequencies, same seed at receiver) or direct sequence (each bit XOR n random bits = n-bit chipping code, signal n× wider).
  • 802.11 original: FH over 79 × 1-MHz, or DS with 11-bit chipping; 2.4 GHz, 2 Mbps. 802.11b 11 Mbps (2.4 GHz). 802.11a 54 Mbps, OFDM, 5 GHz. 802.11g 54 Mbps, OFDM, 2.4 GHz, backward compatible with b.
  • Hidden node: A and C both reach B but not each other → their frames collide at B and neither knows. Exposed node: C hears B→A and wrongly thinks it cannot send to D.
  • MACA: sender sends RTS (with length) → receiver answers CTS. Node hearing CTS → stay quiet. Node hearing RTS only → free to send. MACAW adds ACK. No collision detection: missing CTS → collision → exponential backoff.
  • Distribution system: Access Points (AP) wired together (layer 2). Active scanning: Probe → Probe Response → Association Request → Association Response. Passive scanning: AP sends Beacon. New AP tells old AP.
  • Frame: 4 addresses, ToDS/FromDS bits, data ≤ 2312 bytes, CRC 32, control 16 bits (6-bit type). Both DS = 1: Addr1 = ultimate destination, Addr2 = immediate sender (last AP), Addr3 = intermediate destination (first AP), Addr4 = original source.
  • Mobility: none (early WiMAX), within one base (Bluetooth), between bases (cell, Wi-Fi). Mesh / ad-hoc = peers forward for each other.
  • Bluetooth: 2.45 GHz, ~10 m, PAN, v2.0 = 2.1 Mbps, low power; piconet = 1 master + up to 7 slaves, slaves talk only via master, can be parked. ZigBee: IEEE 802.15.4, lower bandwidth, lower power, cheaper.

Earlier topics (still on the midterm)

  • TCP/IP (slides): Application, Transport, Network, Link — routers have the bottom two. OSI has Physical, Session, Presentation that TCP/IP does not (EX3).
  • Transport layer: reliable message delivery, flow control, error recovery. MAC (hardware) address only travels to the closest router; each hop uses the next hop's HW address. Same LAN ⇔ same network ID (masked address).
  • Packet switching gives resiliency via metadata + routing/forwarding; Sputnik (1957) → ARPA → communication tolerant to partial destruction. ARPANET 1969: UCLA, SRI, UCSB, Utah. Killer apps: e-mail, WWW.
  • Encoding: NRZ, NRZI (flip on 1), Manchester (bit rate = ½ baud rate), 4B/5B (≤ 1 leading 0, ≤ 2 trailing 0s, 80%). FSK = different frequency for 0 and 1.
  • Error detection: parity misses even # of errors; 2-D parity catches 1/2/3-bit; checksum (IP, not link level); CRC (HDLC, DDCMP, CSMA/CD, Token Ring).
