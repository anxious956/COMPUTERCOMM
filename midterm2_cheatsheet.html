Subnetting

  • 1) Feasibility: sum of needs (rounded up to 2k) ≤ block size. 2) per subnet: k = log2(size) host bits → mask 32−k. 3) bits between old and new mask = subnet ID.
  • k-th subnet = write (k−1) in binary into the subnet-ID bits.
  • Multiple masks: round up, largest first, each starts at a multiple of its size; rest = reserve.
  • Groups (ISP): group block = customers × size → prefix; then split per customer. Embedded: subnets of different sizes inside one block.
  • # hosts after /a → /b: 2b−a × (232−b − 2). /20→/27 = 128 × 30 = 3840.

ECE422 MIDTERM 2 — FORWARDING, IP HEADER, JEOPARDY (back)

Forwarding

  • Dst on my network → deliver on that interface; else in table → NextHop; else → default router.
  • Entry matches if D AND mask = DST. Several match → longest prefix wins.
  • Table: DST | Mask | Next Hop | Interface. Direct → Next Hop "–". Next hop = neighbour's IP on the shared net. Default = 0.0.0.0 /0 (replaces several entries). Sort /32 → … → /0. /32 = one host.
  • Routing table: costs, several options. Forwarding table: no cost, one option.
  • Datagram: full dst address in every packet, each forwarded independently, may take different paths, survives failures.
