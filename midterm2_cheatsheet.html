1. QUICK RULES

  • Which byte: /1–8 byte 1 · /9–16 byte 2 · /17–24 byte 3 · /25–32 byte 4. Write in binary only the bytes between where the old and new masks end (CIDR: the first byte that differs). Values don't matter.
  • Mask = 32 − host bits (32 @s = 25 → /27). Subnet bits = new − old; # subnets = 2new−old.
  • 1st subnet = ID 0 = start of block. k-th = ID k−1 → start + (k−1) × size.
  • Network = first @ (host bits 0, cannot be a destination). Broadcast = last = first + size − 1. Hosts = first+1 … last−1. "Address range" includes both ends; "host addresses" doesn't.
  • # hosts /a → /b: 2b−a × (232−b − 2).

5. CIDR (SUPERNETTING)

Method: binary of the first differing byte → count common leading bits → prefix; zero the rest. Why: route aggregation (fewer table entries) + efficiency (class C for 2 hosts 2/255 = 0.78%; class B for 256 hosts 256/65,535 = 0.39%).

6. FORWARDING

  • Algorithm: dst on my network → deliver on that interface; else in table → Next Hop; else → default router.
  • Entry matches if D AND mask = DST. Several match → longest prefix wins.
  • Table: DST | Mask | Next Hop | Interface. Directly connected → "–". Next Hop = neighbour's IP on the shared net. Default 0.0.0.0/0 replaces several entries. Sort /32 → … → /0 (/32 = one host).
  • Routing table: cost, options. Forwarding table: no cost, one option.
  • Datagram: full dst @ in every packet, forwarded independently, may take different paths, survives failures.

8. MTU & FRAGMENTATION

  • MTU = max datagram a network carries (Ethernet 1500, FDDI 4500). Router fragments if datagram > MTU; destination host reassembles (same Ident, Offset gives order, MF = 0 last). Lost fragment → whole datagram lost. DF = 1 & too big → dropped.
  • Why ×8: 13-bit offset for 16-bit length → 216/213 = 8.
Method: (1) data = Length − 20. (2) per frag = (MTU − 20) ↓ multiple of 8. (3) cut; last gets the rest. (4) each: Length = data + 20, Offset = bytes before / 8, MF = 1 except last (last keeps original MF).

9. CONCEPT QUICK ANSWERS (slides)

IP service model?Connectionless, best effort (unreliable)
Forwarding table maps…network number → next hop; every host has a default router
Subnet mask purpose?adds a subnet level to the hierarchy; D AND mask = subnet number
Are subnets visible outside?No, only within the site
CIDR prefix length?Any length 2–32 bits, stored as <length, value>; all routers must understand it
Problem CIDR solves?Backbone table growth + address-space exhaustion (class B)
Overlapping prefixes?Allowed; longest match (171.69.10.5 → 171.69.10/24, 171.69.20.5 → 171.69/16)
Datagram network?Each packet has the full dst @, forwarded independently; no setup; may take different paths
Default route?0.0.0.0/0: used when nothing else matches; replaces many entries
