  • Which byte: /1–8 → byte 1 · /9–16 → 2 · /17–24 → 3 · /25–32 → 4. Binary only for the bytes between the old and new mask (CIDR: first byte that differs).

  • Network = host AND mask (host bits 0) · broadcast = first + size − 1 · hosts = first+1 … last−1.

6. FORWARDING TABLES

Method: 1) list R's directly connected nets → Next Hop "–", Interface = that port. 2) every other net: which neighbour is it behind? → Next Hop = that neighbour's IP on the shared net, Interface = port to it. 3) if all remaining nets (or the Internet) are behind one neighbour → one default 0.0.0.0/0. 4) sort longest prefix first (/32 … /0). Columns: DST | Mask | Next Hop | Interface. Lookup: D AND mask = DST? several match → longest prefix. Routing table: cost, options; forwarding: no cost, one option.

8. MTU & FRAGMENTATION

Method: 1) data = Length − 20. 2) per fragment = (MTU − 20) rounded DOWN to a multiple of 8. 3) cut; the last piece takes the rest. 4) each fragment: Length = data + 20 · Offset = data bytes before it / 8 · MF = 1 except the last · same Ident. Router fragments, destination host reassembles; DF = 1 & too big → dropped. (×8 because 13-bit offset vs 16-bit length.)
Jeopardy Q5: MTU = 61 B, TL = 100 B → offset of the 2nd fragment?
1. data = 100 − 20 = 80
2. per frag = 61 − 20 = 41 → ↓8 → 40
3. frag 1: bytes 0–39 (off 0, MF 1) · frag 2: bytes 40–79
4. offset = 40 / 8
→ Fragment offset = 5
TL 4000, MTU 1500 → fragments? · TL 1000, MTU 310?
1. 4000: data 3980; per frag 1480 (÷8 = 185 ✓)
   1480 | 1480 | 1020 → off 0 | 185 | 370, MF 1 1 0
   Length 1500 | 1500 | 1040
2. 1000: data 980; 310−20 = 290 → ↓8 → 288 (!)
   288 | 288 | 288 | 116 → off 0 | 36 | 72 | 108
Fragment (off 100, MF 1, 800 B data) reaches MTU 420?
1. 420 − 20 = 400 (×8 ✓) → 800 = 400 + 400
2. offsets continue: 100, 100 + 400/8 = 150
3. original MF = 1 → last piece keeps MF = 1
→ off 100 & 150, both MF = 1

9. FACTS FOR VERBAL QUESTIONS

  • IP is connectionless and best effort: packets may be lost, reordered, duplicated or delayed; IP does not fix it.
  • Every datagram carries the full destination address and is forwarded independently (may take different paths).
  • A router uses the longest matching prefix; no match → default router; no default → dropped.
  • Routing table: costs + several options (built by routing protocols). Forwarding table: one next hop + interface, no cost (used per packet).
  • Directly connected network → delivered on the interface, no next hop. Next hop = the neighbour's address on the shared link.
  • Subnetting adds a level inside a site; subnets are not visible from outside. CIDR joins contiguous networks into one prefix → smaller tables, less address waste.
  • Network address (host bits 0) and broadcast (host bits 1) are never host addresses.
  • Routers fragment, the destination host reassembles. One lost fragment = whole datagram lost.
  • Ident: same in all fragments · Offset: ×8 bytes · MF = 0 on the last · DF = 1 → dropped if too big.
  • TTL −1 per router · Checksum covers the header only · Protocol picks TCP (6) / UDP (17) · Hlen in 4-byte words · Options: source / record route.
  • MTU: Ethernet 1500 B, FDDI 4500 B.
