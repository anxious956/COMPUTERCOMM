Solutions

1. Answer: a) 172.80.0.0 – 172.95.255.255
  1. /12 = byte 1 + the first 4 bits of byte 2.
  2. 80 = 0101 0000 → keep 0101; the other 4 bits are host bits.
  3. Smallest 0101 0000 = 80; largest 0101 1111 = 95.
Traps: c) treats it as /16. b) treats it as /13 (80–87). d) adds 31 instead of 15. e) is /11 (010x xxxx = 64–95).
2. Answer: e) 131.14.32.0/19
  1. 224 = 1110 0000 → /16 + 3 = /19.
  2. Byte 3: 44 AND 224 = 0010 1100 AND 1110 0000 = 0010 0000 = 32.
  3. Byte 4 → 0.
Traps: a) only zeroes byte 4. c) ANDs with 248. d) right address, wrong prefix. b) the HW5 answer for host .12.3 (12 AND 224 = 0), not this host.
3. Answer: d) .65 – .94
  1. /27 → block 32 in byte 4 → .64 … .95.
  2. .64 = network, .95 = broadcast.
  3. Hosts = .65 … .94.
Traps: a) is the address range, not hosts. c) keeps the broadcast. b) keeps the network address. e) is /26.
4. Answer: a) 10.8.31.255
  1. /20 → block 16 in byte 3 → 10.8.16.0 … 10.8.31.255 (host part = 12 bits).
  2. Not assignable: host bits all 0 (10.8.16.0) and all 1 (10.8.31.255).
  3. 10.8.16.255 and 10.8.17.0 look special but their 12 host bits are not all 0 or all 1 → valid hosts.
Traps: c) and b) assume a /24 boundary. d) is the last valid host.
5. Answer: d) 229
  1. Class C starts with 110 → 3 bits fixed.
  2. 32 − 3 = 29 free bits → 229 addresses (⅛ of the space).
Traps: a) addresses in ONE class C network. b) NUMBER of class C networks (221). c) one class A network. e) class B.
6. Answer: d) 992
  1. # subnets = 226−22 = 16.
  2. Hosts per subnet = 232−26 − 2 = 62.
  3. 16 × 62 = 992.
Traps: a) all addresses. b) subtracts 2 only once. c) subtracts 1 per subnet (16 × 63). e) subtracts 4 per subnet.
7. Answer: c) 128.17.146.128/26
  1. 64 = 26 → /26; subnet bits = 26 − 22 = 4.
  2. 11th subnet → ID 10 = 1010.
  3. Bytes 3.4 = 1001 0010.1000 0000 = 146.128.
  4. Check: 10 × 64 = 640 = 2·256 + 128 → 144 + 2 = 146, 128.
Traps: b) uses ID 11 (forgets k − 1). a) uses ID 9. d) carries only 1 into byte 3.
8. Answer: e) .97 – .110
  1. 16 = 24 → /28; subnets start at .64, .80, .96, .112.
  2. 3rd subnet = .96/28 → .96 … .111.
  3. Hosts = .97 … .110.
Traps: a) address range. c) keeps the broadcast. d) is the 2nd subnet. b) is the 4th subnet.
9. Answer: a) 172.16.37.0/26
  1. /21 = 211 = 2048 addresses (32.0 – 39.255); needed 1344 ✓.
  2. Masks: 1024 → /22, 256 → /24, 64 → /26.
  3. Largest first: 1024 → 32.0/22 (32.0 – 35.255); 256 → 36.0/24; 64 → 37.0/26 (37.0 – 37.63).
Traps: d) assigns in the listed order. b) forgets the 256-block. c) puts the 64-block inside the 256-block. e) right address, wrong mask.
10. Answer: b) 704
  1. Used: 1024 + 256 + 64 = 1344.
  2. 2048 − 1344 = 704 (from 172.16.37.64).
Traps: e) is what was used. c) forgets the 64-block. a) subtracts 64 twice.
11. Answer: d) 60.40.66.0/24
  1. G1 = 128 × 128 = 16,384 → /18 → 60.40.0.0 – 60.40.63.255.
  2. G2 = 64 × 256 = 16,384 → /18 → starts at 60.40.64.0; each customer 256 @s = /24.
  3. 3rd customer = 64.0 + (3 − 1) × 256 → 60.40.66.0/24.
Traps: c) uses 3 × 256. a) forgets group 1. b) uses group 1's mask. e) adds 3 to the last byte.
12. Answer: c) 24,576
  1. G3 = 256 × 32 = 8,192.
  2. Used: 16,384 + 16,384 + 8,192 = 40,960.
  3. 65,536 − 40,960 = 24,576 (from 60.40.160.0).
Traps: e) is what was used. d) forgets group 3. a), b) are single group sizes.
13. Answer: e) 90.5.6.96/27
  1. /25 = 128 addresses (.0 – .127).
  2. HQ 64 → /26 → .0 – .63.
  3. Rest 64 → 32 each → /27: Branch 1 .64 – .95, Branch 2 .96 – .127.
Traps: a) is Branch 1. d) uses 16 addresses. b) is not a multiple of 32. c) is outside the /25.
14. Answer: a) 77.10.44.0/22
  1. Byte 3: 44 = 0010 1100, 45 = 0010 1101, 46 = 0010 1110, 47 = 0010 1111.
  2. Common leading bits: 0010 11 (6) → /16 + 6 = /22.
  3. Zero the rest: 0010 1100 = 44.
Traps: b) covers only 44–45. c) covers 40–47 (too big). d) /21 must start at 40, not 44. e) host bits not zero.
15. Answer: e) none of the above (60.7.136.0/21)
  1. Byte 3: 137 = 1000 1001, 142 = 1000 1110, 139 = 1000 1011.
  2. Common leading bits: 1000 1 (5) → /16 + 5 = /21.
  3. Zero the rest: 1000 1000 = 136 → 60.7.136.0/21.
Traps: a) right address, /22 covers only 136–139 (142 is outside). b) right prefix, wrong address (128–135). c) host bits not zero. d) covers them but is not the longest prefix.
16. Answer: b) B
  1. Byte 2 of the destination: 27 = 0001 1011.
  2. /12 → first 4 bits 0001 → 16–31 ✓. /13 → first 5 bits 00011 → 24–31 ✓. /14 → first 6 bits 000111 → 28–31 ✗.
  3. Two matches → longest prefix /13 → B.
Traps: a) takes the first match. c) takes the longest prefix without checking that it matches. e) a packet goes to only one next hop.
17. Answer: d) D
  1. 32 = 0010 0000 → first 4 bits 0010 ≠ 0001 → no /12, /13 or /14 match.
  2. 0.0.0.0/0 matches everything → default → D.
Traps: e) it is dropped only if there is no default entry. a) 32 is just outside 16–31.
18. Answer: b) 10.20.0.0, /16, 10.10.1.2, i1
  1. 10.20.0.0/16 is behind Ra.
  2. Next Hop = Ra's address on the network shared with Rk = 10.10.1.2.
  3. Rk reaches Ra through i1.
Traps: a) uses Rk's own address. c) sends it toward Rb. d) "–" is only for directly connected networks. e) right next hop, wrong interface.
19. Answer: d) 0.0.0.0, /0, 10.10.2.2, i2
  1. The Internet is behind Rb → default goes to Rb.
  2. Rb's address on the shared network = 10.10.2.2, interface i2.
  3. Default = 0.0.0.0 with mask /0 (matches every address).
Traps: b) Rk's own address. c) points to Ra. a) /32 would match only the address 0.0.0.0. e) a default needs a next-hop router.
20. Answer: c) 4
10.10.1.0  /24  –          i1
10.10.2.0  /24  –          i2
10.20.0.0  /16  10.10.1.2  i1
0.0.0.0    /0   10.10.2.2  i2
Traps: b) forgets one directly connected network. a) lists only the remote ones.
21. Answer: b)
  1. Routing table: built by the routing protocol, keeps a cost and several options per destination.
  2. Forwarding table: used for every packet, keeps only the chosen next hop and interface.
Traps: a) and c) swap the two tables. Professor's wording: "Rting: cost, options, Fwding: no cost, one option".
22. Answer: a) 792 B
  1. Hlen counts 32-bit words → 7 × 4 = 28 B of header.
  2. Data = Length − header = 820 − 28 = 792 B.
Traps: c) assumes a 20 B header. b) subtracts 7. d) uses 7 × 8.
23. Answer: c) 16
  1. Data = 220 − 20 = 200 B.
  2. Per fragment: 85 − 20 = 65 → round down to a multiple of 8 → 64 B.
  3. Fragments carry 64, 64, 64, 8 B.
  4. 3rd fragment: 128 B before it → 128 / 8 = 16.
Traps: a) offset in bytes. b) uses 65 without rounding. d) is the 4th fragment. e) counts fragments instead of bytes.
24. Answer: c) 4
  1. 200 B of data in pieces of 64: 64 + 64 + 64 = 192, 8 left → a 4th fragment.
Traps: b) 220 / 85 ≈ 2.6 → 3 (forgets every fragment needs its own header and the multiple-of-8 rule).
25. Answer: a) 396 B, offset 138
  1. Data = 1500 − 20 = 1480 B.
  2. Per fragment: 576 − 20 = 556 → round down → 552 B (552 / 8 = 69).
  3. 552 + 552 + 376 → offsets 0, 69, 138.
  4. Last: TL = 376 + 20 = 396 B, offset 138, MF = 0.
Traps: b) forgets the header. c) offset in bytes. d) uses 556 without rounding. e) is the 2nd fragment's offset.
26. Answer: b) Drops it
  1. 1200 B > MTU 1000 B → it would need fragmentation.
  2. DF = 1 (Do not Fragment) forbids it → the router cannot send it → dropped.
27. Answer: c) Ident
  1. All fragments of one datagram carry the same Ident.
  2. Offset gives the position of each piece; MF (Flags) = 0 marks the last one.
28. Answer: b) Class B
  1. Look at the first bits of byte 1: 10111110.
  2. 0… = A, 10… = B, 110… = C, 1110… = D, 1111… = E.
  3. Check in decimal: 10111110 = 190 → inside 128–191 → class B.
Traps: c) reads "101" as "110". a) only if the first bit were 0.
29. Answer: e) 172.16.0.1
  1. Private blocks: 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, 192.168.0.0–192.168.255.255.
  2. For 172.x, the second byte must be 16 … 31: 16 ✓.
Traps: a) 15 is just below the block. c) 32 is just above it. d) 192.169 is not 192.168. b) 11.x is not 10.x.
30. Answer: b) 10.0.0.0 to 10.255.255.255
  1. The class-A private block is one whole class A network: 10.0.0.0/8.
  2. /8 → bytes 2, 3 and 4 are all host bits → 0.0.0 … 255.255.255.
Traps: a) treats it as /16. c) 127.x is loopback, not private.
31. Answer: a) Class D, multicast
  1. 224 = 1110 0000 → first bits 1110 → class D (224–239).
  2. Class D addresses are multicast (group) addresses, not host addresses.
Traps: b) class C ends at 223. c) class E starts at 240.
32. Answer: e) 1/2
  1. Class A = first bit 0 → 31 free bits → 231 addresses.
  2. 231 / 232 = 1/2. (B = 1/4, C = 1/8.)
Traps: c) is class B. b) is class C.
33. Answer: c) 16 network, 16 host
  1. Classful: A = 8 network + 24 host (/8), B = 16 + 16 (/16), C = 24 + 8 (/24).
Traps: b) is the prefix of the class-B PRIVATE block 172.16.0.0/12, not of a class B network. e) 14 is the number of free network bits (214 class B networks), not the prefix.
34. Answer: d) Connectionless and best effort
  1. Connectionless: no setup; every datagram carries the full destination address and is forwarded on its own.
  2. Best effort (unreliable): packets can be lost, arrive out of order, be duplicated or be delayed; IP does not repair this.
