  • OSI (7): Application, Presentation, Session, Transport, Network, Data link, Physical. TCP/IP merges the top three into Application. (Mnemonic: "All People Seem To Need Data Processing".)
  • Encapsulation: each layer adds its header (link layer also a trailer) to the PDU from above. Decapsulation at the receiver, bottom-up.
  • Peer-to-peer logical communication: layer n talks to layer n on the other side; physically data goes down, across, up.
  • Devices: hub/repeater = L1; switch = L2 (links); router = L3 (up to network layer); hosts = all 5 layers.
  • Overhead ratio = header bytes / total bytes sent (or header/data — state which).

2. Protocols & standards

  • Protocol = set of rules; key elements: Syntax (format), Semantics (meaning), Timing (when & how fast).
  • De facto (by practice) vs de jure (by official body).
  • Bodies: ISO, ITU-T, ANSI, IEEE (802.x LANs), EIA; Internet: IETF (writes RFCs), IAB, ISOC, IRTF.
  • RFC maturity: Proposed → Draft → Internet Standard (plus Historic, Experimental, Informational).

3. Networks — basics

  • Data communication criteria: Delivery, Accuracy, Timeliness, Jitter. Components: message, sender, receiver, medium, protocol.
  • Data flow: simplex (one way), half-duplex (both, one at a time), full-duplex (both simultaneously).
  • Network criteria: performance (throughput, delay), reliability, security.
  • Connection: point-to-point vs multipoint. Topologies: mesh (n(n−1)/2 links, n−1 ports each), star, bus, ring.
  • LAN / WAN / MAN; internetwork = network of networks; Internet = hierarchy of ISPs (tier 1 backbone, regional, local).
  • Switching: circuit-switched (reserved resources, telephone) vs packet-switched (store & forward, Internet).

5. Line coding

  • Unipolar NRZ: 1 = +V, 0 = 0 V, whole bit time. Has DC component; no self-clocking.
  • Polar NRZ-L: level = bit. NRZ-I: 1 = invert, 0 = no change.
  • Manchester: transition in the middle of every bit (self-clocking, no DC, 2× bandwidth). IEEE 802.3: 0 = high→low, 1 = low→high (G.E. Thomas is the reverse — state convention).
  • Differential Manchester: always mid-bit transition; 0 = transition at start, 1 = no transition at start.

6. Error detection

  • Single parity: detects any odd number of bit errors; misses all even numbers. Even parity: total 1s even; odd parity: total 1s odd.
  • 2-D parity: row + column parity; detects all 1-, 2-, 3-bit errors, can correct single-bit errors; misses some 4-bit (rectangle) errors.
  • Checksum (1's complement): add words, wrap carries back in, complement → checksum. Receiver: sum everything incl. checksum, complement → 0 means OK.
  • Number of k-bit errors in n-bit word: C(n,k).

7. 1001 has two 1s → P = 1 → codeword 10011. A single parity bit misses every 2-bit error: C(5,2) = 10 undetected strings:
01011, 00111, 00001, 00010, 11111, 11001, 11010, 10101, 10110, 10000 (flipping positions 1-2, 1-3, 1-4, 1-5, 2-3, 2-4, 2-5, 3-4, 3-5, 4-5). All have an odd number of 1s, so all pass.
